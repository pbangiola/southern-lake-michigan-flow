# Roadmap

1. Verify the National Map stream service and pilot extent; export source geometry.
2. Validate line topology and hydrologic direction, particularly Chicago-area diversions.
3. Join USGS measured and modeled discharge, record units and provenance, and scale line widths.
4. Implement SVG and PDF print exports from the same processed dataset.
5. Import and verify the private Paddling · Paul list before deciding which access points can be published.
6. Expand coverage to Indiana and Michigan watersheds.

The initial browser map displays stream geometry only. It must not be described as a discharge map until the flow join is complete.

USGS modern water data API documentation: https://api.waterdata.usgs.gov/docs/
USGS hydrography products: https://www.usgs.gov/3d-hydrography-program/access-3dhp-data-products
